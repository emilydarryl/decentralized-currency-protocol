# Soveroot Stratum V2 reference helper

This test-only Rust program supplies the authenticated coordinator connection
for the Soveroot private labnet miner. It uses the official
`stratum-mining/stratum` v1.4.0 libraries pinned at commit
`0b083ab9411a8a4c74421e90134b77410759b6df` for Noise, framing, Job
Declaration, Mining Protocol messages, and key handling.

The helper has three commands:

- `generate-authority` creates a new test coordinator key file and prints only
  its public key;
- `serve` runs a loopback-only test Job Declarator Server with accepted,
  rejected, disconnecting, stalling, malformed-state, downgrade, ordered
  scenario, and equivocation modes; and
- `declare` reads one miner-created semantic template from standard input,
  authenticates the pinned server over Noise NX, negotiates version 2, obtains
  a token, sends `DeclareMiningJob`, supplies each transaction requested through
  `ProvideMissingTransactions`, opens an extended mining channel, sends
  `SetCustomMiningJob`, and returns one JSON result. The test coordinator asks
  for every non-coinbase transaction and verifies its declared transaction ID.

The helper never constructs, solves, or publishes a block. The same Python
miner that created the template always performs those operations and uses
direct `submitblock`, including after a rejection, timeout, authentication
failure, or disconnect.

Build and test:

```bash
cargo test --locked --release --manifest-path contrib/mining_autonomy/sv2-reference/Cargo.toml
SOVEROOT_SV2_HELPER="$PWD/contrib/mining_autonomy/sv2-reference/target/release/soveroot-sv2-reference" \
  python3 -m unittest discover -s test/mining_autonomy -p 'test_sv2_reference_integration.py' -v
```

This is a reference implementation, not independent interoperability proof.
Noise NX authenticates the coordinator but not the miner. Keys generated by
the demo are disposable labnet keys; private keys must not be committed or
passed on command lines. The program is not production mining or wallet
software and must not be used with assets of value.
